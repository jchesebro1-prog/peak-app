# AI Daily Brief Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Implement `docs/superpowers/specs/2026-10-13-ai-brief-design.md`.

**Architecture:**
- Pure modules in `src/lib/brief/`: slots, sanitizer, fallback, diff, quiet-quote selector, speech text.
- Server builder + loader (blobs; no migration).
- Draft queue run in `after()`, with reusable reply/task server functions extracted from the Inbox actions.
- Home `BriefCard` (server + small client parts).
- Capacitor local notifications.
- Assist feature `brief`.

## Global Constraints

- The spec is binding. Its key values:
  - slots 06:45 / 13:45 America/Chicago;
  - crons `45 11 * * *` and `45 18 * * *`;
  - brief blob id `brief:<userId>:<day>:<slot>`;
  - quiet = sent ≥ 5 business days with no inbound after;
  - max 8 quiet quotes;
  - doFirst 3–5 keys from the snapshot only;
  - Rebuild 3/h;
  - Haiku for brief/tasks/nudges, Sonnet for replies;
  - the `brief` feature is opt-in (default off).
- Model text is untrusted: keep the `<email_thread>` wrapper, sanitize names, and never act on output beyond storing drafts. Nothing auto-sends.
- Every model call goes through `runAssist` (cap, gate, logging). Background calls use `countRate:false`.
- Key-level writes (`patchDocKey`) for new thread and quote fields: `CommThread.preDraft`, `Quote.assistNudge`. Never write the whole doc.
- Client components import only actions, pure modules and types (store imports break only `next build`).
- Process rules:
  - No `server-only`.
  - PGlite is single-process; never touch `.data/pglite`.
  - Never `git stash`; never `git add .superpowers/`.
  - Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - Targeted Edits only in `scripts/test-review-and-spec.ts`.
  - `export PATH=$HOME/.local/node/bin:$PATH`.
- Tests: `scripts/test-brief.ts` (`npm run test:brief`, same mktemp/cleanup pattern), chained into test:specs.
- New npm dependency: `@capacitor/local-notifications`, pinned exactly to a version published ≥ 2 weeks ago that matches `@capacitor/core` major 8.
